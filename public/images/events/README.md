# Events

Photos from sound baths, workshops, retreats, and speaking engagements.

Name each file by event and year so they stay sorted and easy to find:

```
sound-bath-2025.jpg
womens-retreat-2025.jpg
dv-advocacy-workshop-2024.jpg
```

Landscape, around 1600 × 1200. Several photos per event is fine — add `-01`,
`-02` to the end (`sound-bath-2025-01.jpg`).

Event listings themselves come from FreeBlackMarket automatically; these are
supporting photos for the site.
