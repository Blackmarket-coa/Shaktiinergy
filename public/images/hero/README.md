# Hero

The first photo a visitor sees, at the top of the homepage next to
"The Ultimate Feminine Power Lies Within You Too."

**Wired:** `malinda-sound-bath.jpg` — imported by `components/Hero.tsx`,
displayed beside the headline at a 4:5 crop. Replacing it under the same
filename needs no code change; a different name means updating the import.

Pick something with calm, open space on one side — text sits over this image,
so a busy center makes it hard to read. Warm tones suit the site's gold and
teal palette.
